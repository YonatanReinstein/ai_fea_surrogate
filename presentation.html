The Problem: FEA is a Bottleneck

  • FEA solves PDEs on meshes to predict stress, displacement, etc.
  • Each ANSYS simulation takes seconds to minutes per design
  • Design optimization requires evaluating thousands of candidates
  • Brute-force search over parametric dimensions is infeasible
  • Goal: train a fast surrogate model that approximates FEA

Traditional

dims → CAD → Mesh → ANSYS → stress
~30 sec × 10,000 designs = ~83 hours

Surrogate

dims → Neural Network → stress
~5 ms × 10,000 designs = ~50 seconds

Stage 1: Data Generation

  • IRIT parametric CAD model defines geometry from dimensions
    (e.g., 36 parameters d1–d36 for the "arm" geometry)
  • Random sampling of dimension values within bounds
  • IRIT generates hexahedral mesh for each parameter set
  • ANSYS MAPDL runs FEA simulation:
    • Material: Steel (E = 200 GPa, ν = 0.3)
    • BCs: anchored base + applied tip load (1 MN)
    • Output: von Mises stress & displacement at every node
  • Parallel execution: 4 MAPDL instances with retry logic
  • ~1000–3000 samples generated per geometry

Background: Neural Networks in 60 Seconds

  • A neural network is a parametric function f(x; θ) → y
  • Composed of layers: each applies a linear transform
    followed by a non-linear activation (e.g., ReLU)
  • Training = finding θ that minimizes a loss function
    L(θ) = Σ || f(xᵢ; θ) - yᵢ ||²
  • Optimization via gradient descent:
    θ ← θ - α · ∇L(θ)  (backpropagation)
  • Universal approximation: with enough parameters,
    can approximate any continuous function
  • Key advantage: once trained, inference is O(ms)
    vs. O(seconds) for FEA

MLP: Multi-Layer Perceptron

Input (36 dims)
   ↓  Linear(36, 128) + ReLU
Hidden (128)
   ↓  Linear(128, 128) + ReLU
Hidden (128)
   ↓  Linear(128, 3)
Output: [volume, stress, displacement]

The MLP takes dimension values as a flat vector and directly predicts global outputs. Simple and fast, but ignores the spatial/mesh structure.

Key Insight: FEA Meshes Are Graphs

  • A FEA mesh is naturally a graph:
    nodes = vertices, elements define edges
  • Each node carries features:
    position (x,y,z), forces (Fx,Fy,Fz), boundary flag
  • Each node has labels from FEA:
    displacement (Ux,Uy,Uz) and stress (σ_vm)
  • This is exactly the structure Graph Neural Networks are designed to process

Why Graphs Instead of Flat Vectors?

  • Spatial locality: stress depends on neighboring nodes
  • Variable mesh sizes: graphs handle any number of nodes
  • Topology-aware: captures connectivity, not just coordinates
  • Physically meaningful: mirrors how FEA itself works

Graph Data Object (PyTorch Geometric)

Data(
  x          = [N, 7]   # node features
               [x, y, z, Fx, Fy, Fz, anchored]

  edge_index = [2, E]   # bidirectional edges
                         # from element connectivity

  volume     = scalar   # graph-level label
  max_stress = scalar   # graph-level label
  dims       = [1, 36]  # parametric dimensions
)

The GNN Surrogate Model

Architecture

Node features [N, 7]
        ↓
  Encoder MLP:  7 → 128 → 128
        ↓
  6× EdgeConv layers (with residual connections)
    Each layer:
      hᵢ = hᵢ + EdgeConv(hᵢ, edges)
      EdgeConv: MLP([hᵢ || hⱼ]) → max aggregate
        ↓
  Head MLP:  128 → 128 → 1  (per-node scalar)
        ↓
  Global Max Pool: all nodes → 1 scalar
        ↓
  Output: predicted max stress

Key Concepts

  • EdgeConv: for each node, concatenate its features with each neighbor's, apply MLP, take max → learns edge-level interactions
  • Residual connections: h = h + conv(h) → preserves information across layers, stabilizes training of deep networks
  • Message passing: each layer lets nodes "communicate" with neighbors → after 6 layers, information propagates 6 hops across the mesh
  • Global max pool: reduces variable-size node predictions to a single graph-level output (analogous to taking max stress over all nodes)

EdgeConv: Learning from Neighbors

Each mesh node looks at its neighbors, computes a learned function of the pair, and aggregates.

Mathematical Definition

For node i with neighbors N(i):

  hᵢ' = MAX   { MLP( [hᵢ || hⱼ] ) }
       j ∈ N(i)

  [hᵢ || hⱼ] = concatenation of features
  MLP         = learnable non-linear function
  MAX         = element-wise max over neighbors

Physical Analogy

  • Similar to how FEA assembles element stiffness: each element contributes to its nodes' equations
  • EdgeConv: each edge contributes a learned message to its endpoint nodes
  • Max aggregation picks the dominant influence (like max stress from the most stressed neighbor)
  • After 6 layers: each node encodes information from a 6-hop neighborhood in the mesh

Stage 2: Training the Surrogate

Training Setup

  • Dataset: ~3000 FEA simulations stored as graphs
  • Split: 80% training / 20% validation
  • Loss: Mean Squared Error
    L = || σ_pred - σ_true ||²
  • Optimizer: AdamW (lr = 0.002, weight_decay = 1e-4)
  • Scheduler: StepLR (step=20, γ=0.9) — learning rate decays
  • Normalization: forces / 1e6 (MN), stress / 1e6 (MPa)

Training Convergence

Epoch  1:  train = 0.980   val = 0.95
Epoch 10:  train = 0.087   val = 0.09
Epoch 25:  train = 0.031   val = 0.03
Epoch 50:  train = 0.019   val = 0.02

→ ~98% reduction in prediction error
→ val ≈ train: no overfitting

What the Model Learns

  • Mapping: mesh geometry + BCs → stress field
  • Implicitly learns material response without PDEs
  • Inference: ~5 ms vs. ~30 s for ANSYS

Two Surrogate Approaches: MLP vs. GNN

MLP (Multi-Layer Perceptron)

  • Input: flat vector of 36 dimension values
  • Output: [volume, stress, displacement]
  • Architecture: 36 → 128 → 128 → 3
  • Parameters: ~21,000
  • Ignores mesh structure entirely
  • Pro: very fast, simple, no mesh needed at inference
  • Con: cannot generalize to different topologies; treats geometry as a black box

GNN (Graph Neural Network)

  • Input: full mesh graph (nodes + edges + features)
  • Output: predicted max stress
  • Architecture: Encoder + 6×EdgeConv + Head + Pool
  • Parameters: ~400,000
  • Exploits spatial structure of the mesh
  • Pro: topology-aware, mirrors FEA structure, physically meaningful
  • Con: requires mesh generation at inference; more expensive to train

Stage 3: Genetic Algorithm Optimization

Algorithm

  • Population: 200 individuals (each = 36 dimensions)
  • Generations: 400 evolutionary cycles
  • Selection: tournament (k=2), top 80% survive
  • Crossover: blend α·p1 + (1-α)·p2, α ∈ [0.3, 0.7]
  • Mutation: Gaussian noise, σ = 5% of range
    per-gene probability = 16%, rate adapts upward
  • Elitism: top 4 preserved unmutated

Multi-Objective Fitness

Fitness = 0.49 · V_norm       (minimize volume)
       + 0.49 · S_norm       (minimize stress)
       + 0.02 · (1 - D_norm) (diversity)

Stress constraint (soft penalty):
  penalty = max(σ - σ_yield, 0) × weight
  added to volume score

All objectives normalized to [0, 1]

Each generation evaluates 200 designs in milliseconds via the surrogate — no ANSYS needed during optimization.

The Synergy: Surrogate + Evolutionary Search

  • The GA does not need gradients → works even though mesh generation is non-differentiable
  • The surrogate replaces the expensive inner loop (FEA) with a fast forward pass
  • Cost: 200 pop × 400 gen = 80,000 evaluations

Summary & Future Directions

What We Built

  • End-to-end pipeline: parametric CAD → FEA data → surrogate training → design optimization
  • GNN surrogate that respects mesh topology
  • ~6000× speedup over direct FEA evaluation
  • Multi-objective GA finds low-volume, low-stress designs
  • Modular: supports multiple geometries & evaluators

Possible Future Directions

  • Predict full stress fields (per-node), not just max
  • Active learning: let the GA request new FEA data in regions of high uncertainty
  • Transfer learning across geometries
  • Mesh-free approaches (e.g., neural operators)
  • Uncertainty quantification for surrogate predictions

Core idea: leverage the structural similarity between FEA meshes and graph neural networks
to build a fast, topology-aware surrogate that enables efficient design space exploration.
